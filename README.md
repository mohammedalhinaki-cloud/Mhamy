# مهامي

**مهامي** تطبيق أندرويد عربي بسيط للمهام اليومية. يركز على كتابة المهمة، تصنيفها، وإضافة موعد اختياري لها من دون حسابات أو مزامنة.

## الواجهات الثلاث

1. **مهامي** — الشاشة الرئيسية: كل مهامك مع تصنيفات أفقية قابلة للضغط مثل *العمل* و*العائلة* و*المنزل*. يمكنك إضافة تصنيف جديد واستخدامه كفلتر.
2. **مهام بموعد** — تعرض جميع المهام التي اخترت لها تاريخاً ووقتاً، مرتبة حسب الموعد.
3. **التقويم** — تقويم شهري تظهر فيه المهام ذات الموعد كنقاط ملوّنة. اضغط يوماً لرؤية مهامه في بطاقات صغيرة أسفل التقويم.

## المزايا

- إضافة مهمة بعنوان وتصنيف اختياري.
- اختيار **تاريخ ووقت اختياريين** للمهمة عند إضافتها.
- إضافة تصنيفات/فلاتر خاصة بك.
- إنجاز المهمة أو إعادتها وحذفها.
- حفظ كل البيانات محلياً على الجهاز.
- واجهة عربية RTL ودعم الوضع الداكن.

## الهيكلة

لا توجد قاعدة بيانات أو حسابات أو طبقات معقدة. الكود موزع على ثلاثة ملفات مباشرة:

```
app/src/main/java/com/mahami/app/
├── MainActivity.kt  # نقطة تشغيل التطبيق
├── MahamiApp.kt     # الواجهات، التبويبات، الإضافة والتقويم
└── TaskStorage.kt   # نماذج المهام والحفظ المحلي SharedPreferences
```

## البناء محلياً

يتطلب Android Studio Ladybug أو أحدث وJDK 17:

```bash
./gradlew assembleDebug
```

سينشئ Gradle الملف في:

```
app/build/outputs/apk/debug/app-debug.apk
```
