# مهامي

**مهامي** تطبيق أندرويد عربي صغير لكتابة المهام اليومية فقط — بلا حسابات أو قوائم أو تواريخ أو تذكيرات.

## ما الذي يفعله؟

- اكتب مهمة واضغط **إضافة**.
- علّم المهمة عند إنجازها.
- احذف المهمة التي لم تعد تحتاجها.
- يحفظ المهام محلياً على الجهاز، حتى بعد إغلاق التطبيق.
- الواجهة عربية بالكامل وباتجاه من اليمين إلى اليسار.

## ما الذي أُزيل عمداً؟

التقويم، القوائم، الأولويات، الملاحظات، التكرار، التذكيرات، الودجت، الحسابات، المزامنة وقاعدة البيانات. الهدف أن تبقى الشاشة واضحة وسريعة: **اكتب المهمة ثم أنجزها**.

## الهيكلة البسيطة

```
app/src/main/java/com/mahami/app/MainActivity.kt
```

الملف الواحد يحتوي على الشاشة، نموذج المهمة، والحفظ المحلي عبر `SharedPreferences`. لا توجد طبقات Repository أو ViewModel أو Room أو Hilt.

## البناء محلياً

يتطلب Android Studio Ladybug أو أحدث وJDK 17:

```bash
./gradlew assembleDebug
```

سينشئ Gradle الملف في:

```
app/build/outputs/apk/debug/app-debug.apk
```
